# User Management System

Sistema de cadastro de usuários desenvolvido em C# Windows Forms com SQL Server.

## Funcionalidades

- Adicionar usuários
- Buscar usuários por ID
- Atualizar dados dos usuários
- Excluir usuários
- Integração com banco de dados SQL Server

## Tecnologias Utilizadas

- C#
- Windows Forms
- SQL Server
- ADO.NET
- .NET Framework

## Como Executar

1. Clone o repositório.
2. Abra a solução no Visual Studio.
3. Configure a string de conexão com o SQL Server.
4. Execute o script do banco de dados.
5. Inicie o projeto.

## Estrutura do Projeto

- Interface gráfica desenvolvida com Windows Forms.
- Operações CRUD utilizando ADO.NET.
- Persistência de dados em SQL Server.
